SHUVO PAUL — CYBERSECURITY PORTFOLIO
====================================

FILES
- index(1).html — portfolio structure and content (rename to index.html for hosting)
- style.css — visual system, responsive layout, animation and interaction styling
- script.js — navigation, terminal, particles, counters, reveals and project filtering

RUN LOCALLY
1. Keep the HTML, CSS and JS files in the same folder.
2. Rename index(1).html to index.html (recommended).
3. Open index.html in a modern browser, or use VS Code Live Server.

PERSONALIZE BEFORE PUBLISHING
- Replace the portrait placeholder with your own photo. Create an assets folder and use assets/profile.jpg.
- Add your verified certificate URLs and certificate images; do not list learning labs as formal certifications.
- Add your LinkedIn profile URL if you want it displayed.
- Review project descriptions and GitHub URLs to ensure they reflect the latest public repositories.
- Add screenshots of the real applications to strengthen the project case studies.

FEATURES IN THIS UPGRADE
- Responsive dark cyberpunk visual system with red accent lighting.
- Animated hero canvas, scroll progress, loader, reveal effects and interactive terminal.
- Filterable project gallery (Forensics, Endpoint, Linux and Network).
- New lab-notes section for network detection, Linux hardening and vulnerability assessment.
- Keyboard focus states, reduced-motion support and mobile navigation accessibility.

DEPLOYMENT
Upload the three files to GitHub Pages, Netlify or another static host. Rename index(1).html to index.html first. No build tools or package installation are required. Google Fonts are loaded from Google Fonts; local system fallbacks are included.
